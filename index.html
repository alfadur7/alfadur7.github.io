Project

LLM Wiki Newsroom

Open source · MIT · Python + Markdown

Harness engineering applied to knowledge production. Drop your documents into a folder, run one command, and a multi-agent “newsroom” on Claude Code reads them and organises everything into a cross-linked markdown wiki. The agent that writes a page is never the one that reviews it, the authoring guidelines evolve themselves, and published pages come back around as input once they go stale. Local-first, plain markdown and git, a structured alternative to RAG.
